Batch result is a map keyed by 64-character hex feed ID, with null for absent
or outside-age cache entries. I64/U64 are the same NEAR JSON wrappers used by
the current local Pyth adapter; exponent and publication time are numeric.
The source PriceIdentifier parser accepts 64-character hex, while the local
adapter requires lowercase. Pyth serializer emits lowercase feed IDs.

Source update path is payable and calls Wormhole verification. It checks
configured VAA emitter/chain and updates an existing cached feed only for a
greater publication time. Cached prices are not maintained by a passive
read. A reliable Hermes update process and transaction fee/storage funding
must exist before price availability can be claimed.

The receiver's age check accepts future publication time up to age. It is
insufficient on its own for Mandate's tighter future-time guarantee. The
current local engine has its own future-price guard. Negative Pyth timestamps
can panic the receiver conversion; Mandate must handle a failed read safely.
Confidence is provided separately from freshness. The current local adapter
rejects nonpositive price, negative publication time, unsupported exponent,
confidence at least price, and confidence above the mandate slippage budget.
This is a guard on reported uncertainty, not proof of market correctness.
