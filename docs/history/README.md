# Historical reports

These are internal review and checkpoint records from the development of
Mandate. They are kept for the audit trail. They are **not** the current status.
For current status, read [README.md](../../README.md),
[SECURITY.md](../../SECURITY.md), [THREAT_MODEL.md](../../THREAT_MODEL.md) and
[OPERATIONAL-READINESS.md](../OPERATIONAL-READINESS.md).

## Reading notes

- File paths inside the reports are relative to the **repository root**, not to
  this folder.
- Hackathon, judge, track and submission wording describes an earlier scope.
  It is not a current claim.
- Some reports cite local scratch paths and a planning document that has since
  been removed.
- Checksums in `docs/evidence/remediation-files.sha256` were recorded for these
  files at the repository root.
